title: Changelog
description: Notable changes to barca, release by release.
---

The changelog is generated from the conventional commit history, one section per release tag, and
is the same text that appears on each [GitHub Release](https://github.com/barca-orc/barca/releases).
Read it in the repository as
[`CHANGELOG.md`](https://github.com/barca-orc/barca/blob/main/CHANGELOG.md).

The policy for breaking changes is in [the CLI contract](/reference/cli-contract/).

To regenerate it for a release: `git cliff --config cliff.toml -o CHANGELOG.md`.
