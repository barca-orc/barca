An RFC records a design before it was built and the alternatives it rejected. They explain
*why*; for how barca behaves today, use the [reference](/all-pages/). Each RFC states its status
(Accepted, Implemented in a release, or Superseded) at the top. The
[Process & Template](/rfcs/template/) page explains how to write one.
