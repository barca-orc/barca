Barca is for teams that want cached, dependency-aware Python pipelines without running a
platform: one `uv add barca`, no daemon or database to stand up, and `barca serve` only when you
want schedules or a shared history. The pages below put the same pipelines side by side and
measure each tool; each states the versions and date it was measured on. Airflow is compared in
[Same Pipelines in Four Tools](/comparisons/framework-comparison/), next to Dagster and Prefect.
