Read a run's recorded step output (stdout and stderr), without progress messages

Usage: barca logs [OPTIONS] [RUN_ID]

Arguments:
  [RUN_ID]  Exact run id from get/run JSON or history (default: the most recent run; with --follow, the newest running run)

Options:
      --step <STEP>      Function name or exact node id (including a partition key when desired)
      --stream <STREAM>  Only the lines of this stream (default: both) [possible values: stdout, stderr]
  -f, --follow           Print a running run's lines as they arrive and exit when it ends (exit 0 when it succeeded, 130 when it was cancelled, 1 otherwise). With --json, one JSON object per line
      --timestamps       Text output: put each line's arrival time (UTC, milliseconds) before it. JSON always has it as `ts`
      --json             Emit JSON on stdout (the default when stdout is not a terminal)
      --pretty           Emit human-readable output (the default when stdout is a terminal)
      --env <ENV>        Use a separate cache and history for this environment
      --server [<URL>]   Use a server (URL or configured); get/run execute its deployed code
      --local            Use independent local state; ignore the configured server
  -h, --help             Show concise command help
      --examples         Show all command examples without running anything

Examples:
  barca logs                            # the most recent run; stderr names which one
  barca logs -f                         # follow the newest running run until it ends
  barca logs 7f30b3e9 --follow --step report   # follow one step of a run

All examples: barca logs --examples
More: barca docs logs
