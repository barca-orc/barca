Pause assets on a barca server: scheduled runs skip them until resumed (experimental)

Usage: barca pause [OPTIONS] [TARGET]

Arguments:
  [TARGET]  Node or file.py to pause; omit to list paused nodes and schedules

Options:
      --downstream       Also pause every node downstream of the target
      --dry-run          Pause nothing; print what the pause would cover
      --schedule <NODE>  Pause the schedule of this scheduled node instead of nodes
      --until <WHEN>     With --schedule: pause until a duration from now (2h) or an RFC 3339 time
      --json             Emit JSON on stdout (the default when stdout is not a terminal)
      --pretty           Emit human-readable output (the default when stdout is a terminal)
      --env <ENV>        Use a separate cache and history for this environment
      --server [<URL>]   Use a server (URL or configured); get/run execute its deployed code
      --local            Run on this machine; ignore a configured server and this project's barca serve
  -h, --help             Show concise command help
      --examples         Show all command examples without running anything

Examples:
  barca pause clean --server               # scheduled runs skip clean until it is resumed
  barca pause clean --downstream --server  # clean and everything below it
  barca pause clean --downstream --dry-run --server --json   # pauses nothing: covers: {targets, downstream, schedules: [{id, relation}]}

All examples: barca pause --examples
