Metadata backups: list them, put one back in place of the local database, or start over

Usage: barca state <COMMAND>

Commands:
  backups  List the metadata backups, local and in the store, newest first
  restore  Put a metadata backup in place of the local database (the current one is kept aside)
  reset    Start the metadata database over: move it aside and create an empty one (experimental)
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help      Show concise command help
      --examples  Show all command examples without running anything

Examples:
  barca state backups                  # the metadata backups, local and in the store, newest first
  barca state backups --json           # {backups: [{index, name, where, size_bytes, run_id, rows, ...}], local_dir, store}
  barca state restore                  # put this machine's newest backup back in place of .barca/metadata.db

All examples: barca state --examples
More: barca docs remote
