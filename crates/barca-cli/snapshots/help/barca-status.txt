Show every node's cache state, last materialization and artifact shape (read-only)

Usage: barca status [OPTIONS] [ARGS]...

Arguments:
  [ARGS]...  Target(s), then optional files/directories; omit files to discover the project

Options:
      --json             Emit JSON on stdout (the default when stdout is not a terminal)
      --pretty           Emit human-readable output (the default when stdout is a terminal)
  -l, --limit <LIMIT>    Maximum nodes, in topological order (default: every node in JSON, 100 in a human table)
      --all              Show every node (no limit)
      --fields <FIELDS>  Select JSON fields as a comma-separated list; implies --json [possible values: id, name, kind, inputs, partitioned, cache, partitions, last_materialization, last_bytes_change, shape, env, undeclared_env, local, schedule]
      --sample <N>       Include up to N sample rows from each json/parquet/CSV artifact (off by default; pickles are never sampled)
      --state <STATE>    Show only nodes in these cache states (comma-separated): cached, unsynced, stale, never_run, partial, blocked, unknown, always_runs. The summary still counts every node
      --problems         Show only nodes that need attention: not cached (unsynced, stale, never_run, partial, blocked, unknown), a task or sensor whose last run failed, or a paused or failing schedule
      --env <ENV>        Use a separate cache and history for this environment
      --server [<URL>]   Use a server (URL or configured); get/run execute its deployed code
      --local            Use independent local state; ignore the configured server
  -h, --help             Show concise command help
      --examples         Show all command examples without running anything

Examples:
  barca status                             # every node in the project
  barca status pipeline.py                 # table in a terminal (JSON when piped): kind, cache state, last run, shape
  barca status total pipeline.py           # only `total` and its upstream cone

All examples: barca status --examples
More: barca docs status, barca docs agents
