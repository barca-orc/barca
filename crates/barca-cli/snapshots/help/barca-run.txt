Run a task and its dependencies; the task runs every time

Usage: barca run [OPTIONS] <ARGS>...

Arguments:
  <ARGS>...  Target(s), then optional files/directories; omit files to discover the project

Options:
      --refresh <REFRESH>
          Recompute named assets and their downstream dependents: --refresh a,b
      --no-cascade
          Refresh only named assets; cached downstream results may be outdated
      --refresh-all
          Recompute every asset needed by the target
      --partition <KEY=VALUE[,VALUE]|JSON>
          Select keys, e.g. customer=acme; affected collect() fan-ins are skipped
      --batch <[NODE=]none|all|N>
          Override declared batching: none, all, N or NODE=N (experimental)
      --dry-run
          Preview cached and planned work; execute nothing and record no run
  -o, --output <OUTPUT>
          Choose the result output mode (see possible values) [possible values: json, value, pretty]
      --json
          Emit JSON on stdout (the default when stdout is not a terminal)
      --pretty
          Emit human-readable output (the default when stdout is a terminal)
      --agent
          Print plain structured progress on stderr
      --fields <FIELDS>
          Select JSON fields as a comma-separated list; implies --json [possible values: id, kind, action, status, reason, detail, changed, run_hash, artifact, warning, artifact_mismatch, bytes_changed, elapsed_seconds, attempts, import_seconds, partitions, env, undeclared_env, weight, batch]
      --env <ENV>
          Use a separate cache and history for this environment
      --server [<URL>]
          Use a server (URL or configured); get/run execute its deployed code
      --local
          Use independent local state; ignore the configured server
  -h, --help
          Show concise command help
      --examples
          Show all command examples without running anything

Examples:
  barca run publish
  barca run publish --server http://host:8274

All examples: barca run --examples
