Put a metadata backup in place of the local database (the current one is kept aside)

Usage: barca state restore [OPTIONS]

Options:
      --from <N|NAME|PATH>  Backup index (1 = newest), name or database path; default: newest backup
      --json                Emit JSON on stdout (the default when stdout is not a terminal)
      --pretty              Emit human-readable output (the default when stdout is a terminal)
      --env <ENV>           Use a separate cache and history for this environment
  -h, --help                Show concise command help
      --examples            Show all command examples without running anything

Examples:
  barca state restore                  # this machine's newest backup (the newest if it has none)
  barca state restore --from 1         # the newest, whichever machine took it
  barca state restore --from 2         # the second newest

All examples: barca state restore --examples
