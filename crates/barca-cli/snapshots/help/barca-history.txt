Show recent run history, or one run's steps and errors

Usage: barca history [OPTIONS] [RUN_ID]

Arguments:
  [RUN_ID]  One run in detail: its fields, the steps it recorded (the first 1000, failed steps always; --limit and --all change it), and each failed step's error, traceback and how its worker ended

Options:
      --reconcile <RUN_ID>            After verifying a run stopped, record it as interrupted; refuses a proven live owner
      --status <STATUS[,...]>         Only runs with one of these statuses (comma-separated): success, failed, cancelled, error, running, interrupted; not_successful is every one but success and running
      --target <NAME>                 Only runs whose target or job is this node (a function name or node id); runs of every node (`all`) are left out
      --triggered-by <TRIGGER[,...]>  Only runs started this way (comma-separated): manual, api, schedule, client
      --not-triggered-by <T[,...]>    Without the runs started this way (comma-separated): schedule hides the cron ticks and keeps the runs that recorded no trigger
      --search <TEXT>                 Only runs whose run id, target or job contains this text, whatever its case
      --activity                      Instead of the runs: how many started in each of the last 24 hours (UTC), by status and by what started them, with each hour's median time and leading failure, counted over every recorded run; takes --status, --triggered-by, --not-triggered-by, --search
      --since <WHEN>                  Only runs started at or after this: a duration back from now (30m, 24h, 7d, 2w), an RFC 3339 time or a UTC date (2026-10-22)
      --until <WHEN>                  Only runs started before this, written as --since is: with it, a window
  -l, --limit <LIMIT>                 Maximum recent runs (default: every run in JSON, 10 in a human table); with a RUN_ID, the most steps listed (default 1000)
      --all                           Show every recorded run (no limit); with a RUN_ID, every step it recorded
      --json                          Emit JSON on stdout (the default when stdout is not a terminal)
      --pretty                        Emit human-readable output (the default when stdout is a terminal)
      --fields <FIELDS>               Select JSON fields as a comma-separated list; implies --json [possible values: run_id, command, files, target, job, status, steps_total, steps_executed, steps_cached, attempts, started_at, finished_at, elapsed_seconds, triggered_by, scheduled_at, schedule_id, client_run_id, failure, failed_node, error, principal, trigger_reason, cancellation, line, now]
      --env <ENV>                     Use a separate cache and history for this environment
      --server [<URL>]                Use a server (URL or configured); get/run execute its deployed code
      --local                         Run on this machine; ignore a configured server and this project's barca serve
  -h, --help                          Show concise command help
      --examples                      Show all command examples without running anything

Examples:
  barca history                # last 10 in a terminal, every run as JSON when piped
  barca history -l 25          # last 25
  barca history --all          # every recorded run

All examples: barca history --examples
