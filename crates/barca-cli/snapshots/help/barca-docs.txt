Show the built-in manual: concepts, output formats, examples, agent conventions

Usage: barca docs [OPTIONS] [TOPIC]

Arguments:
  [TOPIC]  Topic to show (omit for the index), e.g. types, cache, examples/duckdb

Options:
      --all              Print every topic in one stream
      --json             Emit JSON instead of markdown
      --pretty           Print markdown, the default even when piped (accepted like every read command's --pretty)
      --fields <FIELDS>  Select JSON fields as a comma-separated list; implies --json [possible values: name, summary, content]
  -h, --help             Show concise command help
      --examples         Show all command examples without running anything

Examples:
  barca docs                    # topic index with one-line summaries
  barca docs types              # one topic as markdown
  barca docs examples/duckdb    # a runnable example pipeline

All examples: barca docs --examples
