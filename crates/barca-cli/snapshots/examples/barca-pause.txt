Pause assets on a barca server: scheduled runs skip them until resumed (experimental)

Usage: barca pause [OPTIONS] [TARGET]

Arguments:
  [TARGET]
          Node or file.py to pause; omit to list paused nodes

Options:
      --downstream
          Also pause every node downstream of the target

      --json
          Emit JSON on stdout (the default when stdout is not a terminal)

      --pretty
          Emit human-readable output (the default when stdout is a terminal)

      --env <ENV>
          Use a separate cache and history for this environment

      --server [<URL>]
          Use a server (URL or configured); get/run execute its deployed code

      --local
          Use independent local state; ignore the configured server

  -h, --help
          Show concise command help

      --examples
          Show all command examples without running anything

Examples:
  barca pause clean --server               # scheduled runs skip clean until it is resumed
  barca pause clean --downstream --server  # clean and everything below it
  barca pause pipeline.py --server         # every node of the file
  barca pause --server --json              # {total, paused: [{id, paused_at, via}]}
  barca get clean --allow-paused --server  # run a paused node by hand anyway
