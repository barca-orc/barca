Read a run's recorded step output (stdout and stderr), without progress messages

Usage: barca logs [OPTIONS] [RUN_ID]

Arguments:
  [RUN_ID]
          Exact run id from get/run JSON or history (default: the most recent run; with --follow, the newest running run)

Options:
      --step <STEP>
          Function name or exact node id (including a partition key when desired)

      --stream <STREAM>
          Only the lines of this stream (default: both)

          Possible values:
          - stdout: What the steps printed to stdout
          - stderr: What the steps wrote to stderr: logging, warnings, tracebacks of failed attempts

  -f, --follow
          Print a running run's lines as they arrive and exit when it ends (exit 0 when it succeeded, 130 when it was cancelled, 1 otherwise). With --json, one JSON object per line

      --timestamps
          Text output: put each line's arrival time (UTC, milliseconds) before it. JSON always has it as `ts`

      --json
          Emit JSON on stdout (the default when stdout is not a terminal)

      --pretty
          Emit human-readable output (the default when stdout is a terminal)

      --env <ENV>
          Use a separate cache and history for this environment

      --server [<URL>]
          Use a server (URL or configured); get/run execute its deployed code

      --local
          Use independent local state; ignore the configured server

  -h, --help
          Show concise command help

      --examples
          Show all command examples without running anything

Examples:
  barca logs                            # the most recent run; stderr names which one
  barca logs -f                         # follow the newest running run until it ends
  barca logs 7f30b3e9 --follow --step report   # follow one step of a run
  barca logs --step report              # one step of the most recent run
  barca logs 7f30b3e9 --stream stderr   # only stderr: logging, warnings, tracebacks
  barca logs 7f30b3e9 --timestamps      # each line after its UTC arrival time
  barca logs 7f30b3e9 --pretty          # recorded lines, without progress messages
  barca logs 7f30b3e9 --step report --pretty   # one function name or exact node id
  barca logs 7f30b3e9 --json            # [{node_id, stream, ts, line}] in recorded order
  barca logs 7f30b3e9 --env dev         # read another environment's local history
  barca logs --server -f                # follow the newest running run on the server
  barca logs 7f30b3e9 --local           # this machine's records, despite a configured server
