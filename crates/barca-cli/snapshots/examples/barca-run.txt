Run a task and its dependencies; the task runs every time

Usage: barca run [OPTIONS] <ARGS>...

Arguments:
  <ARGS>...
          Target(s), then optional files/directories; omit files to discover the project

Options:
      --refresh <REFRESH>
          Recompute named assets and their downstream dependents: --refresh a,b

      --no-cascade
          Refresh only named assets; cached downstream results may be outdated

      --refresh-all
          Recompute every asset needed by the target

      --partition <KEY=VALUE[,VALUE]|JSON>
          Select keys, e.g. customer=acme; affected collect() fan-ins are skipped

      --batch <[NODE=]none|all|N>
          Override declared batching: none, all, N or NODE=N (experimental)

      --dry-run
          Preview cached and planned work; execute nothing and record no run

  -o, --output <OUTPUT>
          Choose the result output mode (see possible values)

          Possible values:
          - json:   One-line JSON (default when stdout is not a terminal)
          - value:  Just the final_output value, pretty-printed
          - pretty: Human-friendly with timing info (default when stdout is a terminal)

      --json
          Emit JSON on stdout (the default when stdout is not a terminal)

      --pretty
          Emit human-readable output (the default when stdout is a terminal)

      --agent
          Print plain structured progress on stderr

      --fields <FIELDS>
          Select JSON fields as a comma-separated list; implies --json

          [possible values: id, kind, action, status, reason, detail, changed, run_hash, artifact, warning, artifact_mismatch, bytes_changed, elapsed_seconds, attempts, import_seconds, partitions, env, undeclared_env, weight, batch, batch_execution]

      --env <ENV>
          Use a separate cache and history for this environment

      --server [<URL>]
          Use a server (URL or configured); get/run execute its deployed code

      --local
          Use independent local state; ignore the configured server

  -h, --help
          Show concise command help

      --examples
          Show all command examples without running anything

Examples:
  BARCA_REMOTE=off barca run deploy pipeline.py   # local artifacts and history for this process
  barca run deploy                                     # find the task anywhere in the project and run it
  barca run deploy pipelines/                          # only read files under pipelines/
  barca run deploy pipeline.py                         # task runs; upstream assets come from cache
  barca run deploy pipeline.py --refresh fetch,clean   # re-materialize these and everything downstream of them
  barca run deploy pipeline.py --refresh fetch --no-cascade   # re-materialize only fetch; downstream stays cached
  barca run deploy pipeline.py --refresh-all           # re-materialize every upstream asset
  barca run deploy pipeline.py --dry-run --refresh fetch   # preview: which steps run, which are cached
  barca run notify pipeline.py --partition region=emea   # the task's cone, for the emea keys only
  barca run notify pipeline.py --batch all             # override batch= of the cone's batched nodes for this run
  barca run deploy pipeline.py --json                  # JSON even in a terminal (the default when piped)
  barca run deploy pipeline.py --pretty                # summary for humans (the default in a terminal)
  barca run deploy pipeline.py --fields id,status,reason   # JSON with each entry of `steps` trimmed
  barca run check_a,check_b pipeline.py                # several tasks in one run; shared upstream runs once
  barca run check_a,check_b pipeline.py --dry-run      # preview the union of both cones
  barca run deploy --server --agent                    # run it on the configured barca server (barca docs server-mode)
  barca run deploy pipeline.py --local                 # run here and post nothing to a configured server
  barca list pipeline.py                               # not sure of the name? list assets and tasks first
