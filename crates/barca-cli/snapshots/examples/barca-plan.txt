Parse source files and emit the execution plan as JSON

Usage: barca plan [OPTIONS] [FILES]...

Arguments:
  [FILES]...
          Python files or directories; default: discover the project

Options:
      --partition <KEY=VALUE[,VALUE]|JSON>
          Select keys, e.g. customer=acme; affected collect() fan-ins are skipped

      --json
          Accepted for symmetry with the other commands: the plan is always pretty-printed JSON, so this changes nothing

      --pretty
          Accepted for symmetry with the other commands: the plan is always pretty-printed JSON, so this changes nothing (there is no table form)

  -h, --help
          Show concise command help

      --examples
          Show all command examples without running anything

Examples:
  barca plan                          # the whole project
  barca plan pipeline.py              # phases and steps that would run; nothing executes
  barca plan pipeline.py other.py     # several files form one DAG
  barca plan pipeline.py --partition region=emea   # only the emea keys; skipped fan-ins listed
  barca plan pipeline.py --json       # the same JSON: --json and --pretty are accepted and change nothing
